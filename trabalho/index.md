# O trabalho do dia a dia

Esta é a parte do manual que você vai usar de verdade. Cada página resolve uma
tarefa concreta, do jeito que ela aparece no seu dia.

A ordem abaixo é a de um trabalho que nasce e se encerra. **Você não precisa
percorrer tudo:** muita organização vive bem usando só as quatro primeiras
páginas, e nunca aciona aprovação nenhuma.
